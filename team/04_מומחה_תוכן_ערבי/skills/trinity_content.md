# 🗣️ תוכן חוק השילוש (לדף נחיתה)

## הפורמט (3 שכבות תמיד)
```
ערבית אותנטית מנוקדת | תעתיק עברי מנוקד פונטי | תרגום עברי
مَرْحَبَا | מַרְחַבַּא | שלום
```
> בדף נחיתה לקהל שלא קורא ערבית: **התעתיק המנוקד בולט במרכז**, הערבית דקורטיבית מעל, התרגום מתחת.

## טבלת אכיפת להג צפוני
| משמעות | ✅ צפוני | ❌ אסור |
|--------|---------|---------|
| עכשיו | إِسَّا / אִסַּא | هَلَق / הלק |
| אני רוצה | بِدِّي / בִּדִּי | بَدِّي / בַּדִּי |
| יש לי | عِنْدِي / עִנְדִי | عَنْدِي / עַנְדִי |
| הולך | بَرُوح / בַּרוּח | رايِح |
| לא / שלילה | مِش / מִש | مُش |
| סיומת נקבה | קַהְוֶה (-E) | קַהְוַא (-A) |

## מילים מומלצות ל-Hero / כרטיסי הדגמה
| תעתיק מנוקד | ערבית | תרגום |
|--------------|-------|--------|
| מַרְחַבַּא | مَرْحَبَا | שלום |
| כִּיף חַאלַכּ | كِيف حالَك | מה שלומך |
| קַהְוֶה | قَهْوِة | קפה |
| בִּדִּי אַחְכִּי עַרַבִּי | بِدِّي أَحْكِي عَرَبِي | אני רוצה לדבר ערבית |
| יַאלּא נִחְכִּי | يَلّا نِحْكِي | בוא/י נדבר |
| אִסַّא | إِسَّا | עכשיו |

## עוגנים פונטיים (טיפ למקומי)
- ح (ח גרונית), ع (ע עמוקה), ق (ק נחצית), ط צ — להוסיף "קוביית הגייה" קצרה.
- הבדל עיר/כפר: ق נשמעת לעיתים כ-א' בעירוני.
