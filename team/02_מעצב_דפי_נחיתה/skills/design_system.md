# 🎨 מערכת עיצוב — Hi-Tech לבן + כאב שחור דרמטי

> כיוון העיצוב של דף הנחיתה (לפי ה-blueprint של הבעלים): לבן נקי ונושם, עם סקשן כאב שחור דרמטי לשבירת תבנית.

## פלטת צבעים (CSS Variables)
```css
--white:#ffffff;   /* רקע ראשי — חוויה הייטקיסטית נושמת */
--bg-alt:#f6f9fb;  /* סקשנים מתחלפים / כרטיסים */
--ink:#000000;     /* שחור דרמטי — H1 + סקשן הכאב */
--gray:#5a6472;    /* טקסט משני */
--teal:#00B5A1;    /* טורקיז אנרגטי — כפתורים, הדגשות */
--teal-dark:#00897B; /* טורקיז כהה — hover, נגיעות */
--teal-soft:rgba(0,181,161,.1);
--border:#e8edf3;
```
> אסור: כתום, צהוב. הדגשה = טורקיז בלבד.

## טיפוגרפיה — סאנס-סריף בלבד
- **Rubik** (ראשי) + **Heebo** (גיבוי) לעברית.
- **Noto Sans Arabic** לערבית (סאנס-סריף, נקי).
- ❌ אין פונטים מסולסלים (Amiri / גופני תנ"ך) — לא מתאים ל-EdTech.

## כפתורים
- ראשי: רקע `#00B5A1` + טקסט **שחור** (קונטרסט שואב-קליקים).
- hover: רקע משתנה ל-`#00897B`.

## Bento Grid
- כרטיסיות א-סימטריות, רדיוס פינות **16px**.
- הצללה עדינה: `box-shadow: 0 4px 15px rgba(0,0,0,.05)` — תחושת ריחוף ויוקרה מעל הלבן.
- hover: הרמה `translateY(-6px)` + הצללה חזקה יותר.

## סקשן הכאב (שבירת תבנית)
- רקע **שחור #000**, טקסט לבן, כרטיסי #0d0f12 — ממחיש את ה"חושך"/התסכול.
- אייקון טורקיז רך בכל כרטיס.

## כרטיס חוק השילוש (אלמנט חתימה)
```
ערבית מנוקדת (Noto Sans Arabic)  🔊
תעתיק עברי מנוקד (מודגש בטורקיז, Rubik/Heebo)  ← הכי בולט
תרגום עברית (אפור)
border-right: 3px solid teal · רדיוס 12px
```

## אנימציה
- reveal-on-scroll עדין (IntersectionObserver, opacity+translateY).
- pulse על כפתור הגייה.
- `prefers-reduced-motion` → כיבוי.
