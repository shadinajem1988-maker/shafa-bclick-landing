# 🌐 דף נחיתה — שפה בקליק

דף נחיתה ל"שפה בקליק", ממוקד ערבית מדוברת בלהג צפוני (+ קריאה וכתיבה, ובהמשך עוד שפות).
**עיצוב:** Hi-Tech לבן נקי + סקשן כאב שחור דרמטי · טורקיז `#00B5A1` · פונטים סאנס-סריף (Rubik/Heebo/Noto Sans Arabic).
קובץ יחיד עצמאי (`index.html`) — פותחים בכל דפדפן, מעלים לכל אחסון.

## 🧱 מבנה הדף (6 סקשנים, לפי ה-blueprint)
1. **Hero** (לבן) — H1 שחור, וידאו אווירה, CTA "שיחת אבחון".
2. **כאב** (שחור דרמטי) — Bento של 3: פוסחא / אותיות / ניתוק.
3. **פתרון + חוק השילוש** (לבן) — שיטה + כרטיס הגייה חי.
4. **תמחור** — טוגל בין "מדוברת" ל"קריאה וכתיבה", 4 מסלולים.
5. **אקו-סיסטם ועתיד** — שפות נוספות + איסוף לידים ל-VOD.
6. **CTA סופי** — טופס אבחון + וואטסאפ.
